# Evaluation datasets

- `qa/`: source QA sets and protected QA fixtures.
- `passages/`: source and test passages.
- `mcq/`: active MCQ rewrites, backups, and A/B test sets.
- `metadata/`: dataset metadata records.
- `perturbations/`: shared and chapter-specific defect banks.
- `pseudonym_remap/`: per-chapter pseudonym mappings.
- `cuv/`: downloaded CUV reference data, when generated.
